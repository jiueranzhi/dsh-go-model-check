# 模型检测（dsh-go 原生插件）

为当前主机已保存的渠道提供单模型和批量文本检测。无需再次填写 API Key。

## 使用

1. 点击输入框上方「模型检测」，或在对话详情的「插件」／「全部功能」进入面板。
2. 选择渠道，等待模型列表加载；点模型行勾选，可「全选本页」，跨页保留选择。
3. 点「开始检测」，核对数量及费用提示，再点「确认开始」。每轮最多 50 个模型，串行执行。
4. 查看进度；点结果行查看总耗时、首段文本等待时间、返回摘要和失败说明。
5. 可随时「停止检测」。停止后，「仅测未开始项」不会重放已取消或结果未知的请求，且需要重新确认。

## v0.1.2：结果展示优化

- 没有待确认操作时，不再渲染空的确认布局，移除「暂无数据」占位卡。
- 成功结果显示「已正常完成」，隐藏错误分类、诊断提示及未采集的 HTTP 状态；不推断或伪造 HTTP 200。
- 失败、超时、取消、输出截断等非成功结果仍保留诊断信息。已取得的 HTTP 状态及其来源仍照实显示。
- 开始时间按北京时间（Asia/Shanghai，UTC+8）显示为 `2026-11-21 05:05:08`，内部时间仍保存原来的 UTC 值。
- 仅修改展示，不改变检测请求、预算、成功标准、渠道或凭据。

此版本改动了 lib 代码，需要在方便时自行重启本机引擎才能加载。重启会中断进行中的回复并清空内存中的检测结果；如有需要，请先保留截图。重新打开面板后，顶部应显示「检测器 v0.1.2」。无需重新安装或重新测试真实模型来加载界面。

## v0.1.1：三方渠道错误诊断修复

旧版遗漏了三方适配器的 TRANSPORT、TIMEOUT、INVALID_REQUEST 等错误分类，因此不同失败都可能显示成同一句通用提示。这不能证明中转站或模型下线。

新版结果增加「错误分类」「请求阶段」「诊断提示」，并区分本地未派发、网络传输失败、上游超时、参数拒绝及响应流异常。HTTP 状态若只能从明确的错误信息中识别，会标注来源；「适配器未提供」不代表 HTTP 200，也不代表 Key 错误。仅识别白名单模式，不回显原始异常正文。

这是诊断展示修复，尚不能确定旧失败的实际原因。旧结果没有保留原始错误，无法倒推出缺失的分类。修复没有更改输出预算、渠道设置或自动重试策略。

链接安装无需重新安装；此更新改动了 lib 代码，需要在方便时自行重启本机引擎后生效。重启会中断正在进行的回复、清空检测结果，建议先保留所需截图；重新打开面板，顶部应显示「检测器 v0.1.1」。之后可按需只测一个模型，真实请求仍可能计费。

## 检测的含义

- 通过引擎已有适配器发送独立的「只回复 OK」请求，不发送聊天历史，不执行工具，不改变当前对话模型或渠道。
- 每项最多 50 秒、256 输出 token；仅在模型声明支持时关闭思考，否则沿用默认档位。
- 正常结束且有可见文本判为成功，不强制输出严格等于 OK。
- 无文本、输出截断、缺少结束事件、失败、超时、取消分别展示；思考耗尽预算不代表渠道一定不可用。
- 每次检测只验证当次文本生成，不验证模型真实身份、图像和工具调用，也不保证后续一直可用。
- 每个模型只派发一次，插件不自动重试；请求仍经过引擎已有中间件。
- 401、403、429 或明确的余额／配额失败会停止本轮。其他模型错误继续下一项。

## 费用、取消与隐私

- 真实生成可能产生费用，只有点按并确认后才派发；进入面板和读取目录不会执行生成。
- 停止会立即请求中止当前调用，不再派发后续模型，但服务端仍可能计费。
- 若适配器不响应取消，暂停队列并持有进程共享锁，清理完成前不允许新请求；同进程卸载再启用也不会绕过该锁。
- 关闭前请先点停止。桥接在无订阅约 30 秒后才回收面板；不能把关闭面板当作立即取消。
- 不直接读取或保存 Key。错误只展示白名单分类及有效状态码，不回显原始异常、请求头或错误响应体。
- 摘要和名称有常见凭据格式脱敏及长度限制，但不应将返回摘要视为绝对无敏感内容。
- 选择和最近一轮结果只存内存；引擎重启后清空。不保存永久历史。

## 检查与测试

```sh
node "${DSH_HOME:-$HOME/.dsh}/skills/dsh-go-plugin/kit/bin/check.mjs" \
  "${DSH_HOME:-$HOME/.dsh}/dsh-go/plugins/local-model-check" --load --app 1.2.0

node --test "${DSH_HOME:-$HOME/.dsh}/dsh-go/plugins/local-model-check/test/"*.test.mjs
```

全部自动测试使用模拟模型，不访问真实中转站。测试宿主来自当前手机的原生插件技能包。

## 安装与更新

```sh
dsh plugin --profile web add "${DSH_HOME:-$HOME/.dsh}/dsh-go/plugins/local-model-check"
```

这是链接安装，源目录不可删除。清单自动重读；以后修改 lib 代码需要在 App 的引擎页重启引擎。

卸载命令：`dsh plugin --profile web remove local-model-check`。卸载后可保留源目录便于再次安装。
